7 Critical Decisions to Make in Week 1

Get these wrong now and it costs 1–2 weeks of rework later.

01
Use Next.js — not plain React
Plain React is a client-side app — Google can't easily read it, so your donation page won't show up in search results. Next.js gives you fast pages, great SEO, and built-in image optimisation for the photo-heavy gallery. This is a must, not optional.
Decide Now
02
Build a "swap-able" payment layer from Day 1
You'll start with Pesapal but will likely move to a better solution later. If you wire the payment code directly into every page, migrating means rewriting the whole checkout. Wrap all payment calls in one file (e.g., payment-service.js) — then swapping providers takes an hour, not a week.
Architecture
03
Remove PlanetScale from all plans immediately
PlanetScale killed its free plan in April 2024. The cheapest plan is now $39/month. It's essentially gone as a budget-friendly option. Anyone on the team who researched databases before mid-2024 has outdated info. Use Supabase instead.
Outdated Info
04
Add a CMS — the brief forgot it
There is no content management system in the brief. Without one, the client needs a developer to change any text, photo, or project update — forever. Add Sanity.io (free) so the client can edit the site themselves. This must be agreed in Week 1.
Gap Alert
05
Start the US tax deductibility process now
US donors giving $250+ often won't donate if they can't get a tax receipt. Kenya-based NGOs are not automatically tax-deductible in the US. The team needs to advise the client to pursue a "fiscal sponsorship" with a US charity. This takes 2–6 months — start now, it runs alongside development.
Legal Priority
06
Put the admin system inside the main app — not separate
Build the admin section at /admin in the same Next.js project, protected by login. Don't build a separate admin app. One codebase = half the maintenance, half the security risk.
Architecture
07
Use Brevo for newsletters — not Resend
Resend is great for automated emails (receipts, confirmations). But it can't manage a subscriber list, send campaigns, or handle unsubscribes. Use Brevo (free) for newsletters and keep Resend for system emails.
Tool Mismatch

Payment Gateway — The Hard Truth

This is the most complicated decision in the whole project. Here's what's actually going on.

🚨
Stripe does NOT work directly in Kenya. Stripe only fully supports 46 countries — Kenya is not one of them. You'd need to set up a US company to use Stripe, which takes months and costs money every year. Don't plan for Stripe unless the NPO already has a US entity.
⚠️
Zeffy's "0% fees" doesn't apply to Kenya-based NGOs. Zeffy is a North America–only platform. Their 0% model also prompts donors for a 15–17% "tip" to Zeffy — which some donors find confusing or off-putting.

Phase 1 — Launch

Use Pesapal

It works in Kenya, accepts USD from US credit cards, and can settle in USD to a Kenya bank account. Not perfect — but it gets you live on time.

Phase 2 — 3 Months Post-Launch

Switch to Donorbox + PayPal

Donorbox gives you recurring donations, automatic tax receipts, donor portal, and US-familiar checkout. Use PayPal as the processor since Stripe isn't available.

The Real Unlock — Start Now

Get a US Fiscal Sponsor

A US charity receives donations on your behalf and passes them to you. Donors get a US tax deduction. Platforms like GlobalGiving offer this. It takes 2–6 months — start the application in Week 1.

Donation Page — What Actually Converts

The average NPO donation page converts 11–12% of visitors. Best-in-class pages hit 28%+. Here's the difference.

Conversion Fact

Default to Monthly Giving

Set the donation form default to "Monthly" not "One-time." This one change increases monthly donors by 30–50% with no other changes. It's backed by hundreds of A/B tests.

Trust Signal

Show Real Photos, Never Stock

US donors giving to African NGOs can't visit in person. Real photos of named beneficiaries with locations are their proof the organisation is real. Stock photos destroy trust.

Impact Framing

Tie Money to Outcomes

Don't just say "donate." Say: "$25 = 3 months clean water for one family." "$100 = safe sanitation for a classroom." Make the impact concrete and specific.

Trust Badge

Add Third-Party Ratings

Charity Navigator, GuideStar, and BBB badges should be visible on the donation page — not buried in the footer. US donors check these before giving.

Project Trust

Show a GPS Project Map

A map with pins showing exactly where projects are located (e.g., "Well #14 — Kajiado County, installed March 2024") is the highest-trust feature for an Africa-based NPO. Charity: water built their reputation on this.

Common Mistake

Be Clear About Tax Deductibility

Don't leave this vague. If donations aren't tax-deductible in the US yet, say so honestly: "We are working toward US tax deductibility." Donors respect transparency.

Content Management — The Missing Piece

The brief doesn't mention a CMS. This is a critical gap that will cause ongoing problems if ignored.

🔴
Without a CMS, every content change needs a developer. That means: client wants to add a new project photo → files a request → developer makes a pull request → deploys. This creates a bad long-term client relationship and unpaid support work.
✓ Recommended

Sanity.io

Free for 3 users and 10GB. Integrates cleanly with Next.js. The client gets a clean, simple editing panel at yoursite.sanity.studio to update projects, photos, team bios, and news — no developer needed. Changes go live within 60 seconds.

Free forever for this scale
Alternative

Runs inside the Next.js app itself — one codebase. Good if the team prefers everything together. More technical to set up, but no separate service to manage.

Advanced option
Avoid

Strapi / Directus

Both are self-hosted, meaning you need a VPS server to run just the CMS. Extra cost, extra DevOps work, extra security to maintain. Not worth it when Sanity is free and hosted.

Security — Vincent's Priority List

What the security specialist needs to address, in order of importance.

  • 🛡
    Use Pesapal's hosted checkout page — never touch card dataIf Pesapal's checkout page handles the payment (user goes to Pesapal's page to type their card), your server never sees card numbers. This means you only need basic PCI compliance (SAQ-A). If you build a custom card form, you'd need expensive quarterly security audits. Don't build custom card forms.
  • 🔑
    Use Supabase Auth — don't build your own login systemCustom login systems are the #1 source of security vulnerabilities in small projects. Supabase Auth is enterprise-grade, free, and handles tokens, sessions, and OAuth (Google login) securely.
  • 👥
    Set up 4 admin roles in SupabaseSuper Admin (everything), Finance Manager (view transactions only), Content Manager (edit website content), Inventory Manager (track assets). Each role only sees what they need — enforced at the database level, not just the app.
  • 🌐
    Put Cloudflare in front of the site — free tierCloudflare's free plan gives you DDoS protection, a Web Application Firewall, and rate limiting. Critical for a donation page: if the site goes down during a campaign, you lose real donations. Takes 30 minutes to set up.
  • 🇰🇪
    Register with Kenya's data protection officeKenya's Data Protection Act (2019) requires any organisation handling personal data to register with the Office of the Data Protection Commissioner (ODPC). The site collects donor names, emails, and payment info — registration is legally required.
  • 🍪
    Add a cookie consent bannerGA4 (Google Analytics) uses cookies. Kenya's Data Protection Act and international best practice require asking users for consent before tracking them. Add a simple cookie banner on first visit.
  • 🔐
    Enable 2FA on all admin accounts at launchEspecially the payment admin and finance accounts. A compromised admin account could expose donor data or redirect payment notifications.

SEO & US Donor Growth

How to get US donors to find this site through Google — including a $10,000/month free advertising programme.

🎯
The NPO can qualify for Google Ad Grants — $10,000/month in FREE Google Ads. Kenya-based NGOs (registered with the NGO Coordination Board, Registrar of Societies, or as a company limited by guarantee) are eligible. Apply during development — approval takes 2–4 weeks.
SEO Requirement

Why Next.js is Non-Negotiable

Plain React renders pages in the browser — Google sees a blank page until JavaScript loads. Next.js sends complete HTML to Google, so every project page, gallery caption, and impact story gets indexed. For an NPO trying to rank for "clean water charity Kenya," this is the baseline.

What US Donors Search For

High-intent: "clean water charity Africa," "donate clean water Kenya," "water sanitation nonprofit"

Trust-seeking: "transparent water nonprofit," "water charity low overhead"

These are achievable with content — not paid ads.

Top 10 Project Risks

Know what could go wrong and how to stop it.

No US tax deductibility at launch
High

Experienced US donors giving $250+ often won't donate without a tax receipt. This suppresses conversion.

Fix: Start fiscal sponsorship application in Week 1. Add honest disclosure on donation page.

Pesapal checkout unfamiliar to US donors
High

US donors don't recognise Pesapal. Some will abandon checkout when redirected to an unknown payment brand.

Fix: Add trust copy near the donate button: "Secure payment via Pesapal, licensed East Africa payment processor." Track abandonment rates from Day 1.

No CMS = permanent developer dependency
High

Every text change, new project photo, or team update requires a developer's time post-launch.

Fix: Integrate Sanity.io in Week 1. Non-negotiable.

7-week timeline with no buffer
High

Any integration problem (Pesapal API, Supabase setup, client photo delays) could push the launch date.

Fix: Define a strict MVP. Launch the 6 pages + payments + newsletter signup + basic admin. AI chatbot, advanced analytics, and full inventory UX are Phase 2.

Gallery kills page speed for US visitors
Medium

Large uncompressed field photos from Kenya will load slowly for US visitors. Slow pages = higher bounce rate on the donation page.

Fix: Cloudinary with f_auto,q_auto parameters. Test loading speed from a US network using Chrome DevTools throttling.

Supabase free tier pauses unexpectedly
Medium

Supabase's free projects pause after 7 days of inactivity. If the site goes live on a free project, a quiet week could take the database (and entire site) offline.

Fix: Upgrade to Supabase Pro ($25/mo) before launch. Or set a cron job to ping the database daily.

Client scope creep on admin system
Medium

"100K component" suggests a fixed-price admin build. Without a locked spec, the client may add features mid-build.

Fix: Define exactly 6 admin modules in a signed spec document before any code is written. All additions require a formal change request.

Google Ad Grants rejected for site quality
Medium

Google rejects grant applications if the website has thin content, broken pages, or unclear mission pages.

Fix: Apply only once the site is fully content-populated. Every page needs real content — not placeholders.

Security breach exposing donor data
Low Probability

Low probability but catastrophic impact. A breach of US donor PII could end the organisation's US fundraising permanently.

Fix: Supabase RLS on all tables. Cloudflare WAF. Never store card data. 2FA on admin accounts. Rotate API keys post-launch.

US banks flagging Kenya transfers
Lower Now

Previously, Kenya's FATF grey list status caused some US banks to slow or block Kenya-bound transfers. Kenya was removed from the grey list in June 2024.

Fix: Kenya is off the grey list — reduced risk. Fiscal sponsorship eliminates this entirely by routing funds through a US entity.

Week 1 Checklist

Before writing any production code, validate these first.

  • 💳
    Test Pesapal with a real international Visa cardMany Pesapal integration issues only appear with non-Kenyan cards. Borrow a US-issued card and run a test transaction. Confirm USD collection and settlement flow works end-to-end before building the donation page.
  • 🏦
    Confirm the NPO has a USD forex bank accountPesapal settles USD to a USD-designated bank account in Kenya. Most major Kenyan banks (Equity, KCB, Co-op) offer these. If the NPO doesn't have one, opening it takes 5–10 business days.
  • 📋
    Confirm the NPO's registration typeIs it registered with the NGO Coordination Board? Registrar of Societies? Company limited by guarantee? This determines Google for Nonprofits eligibility and which fiscal sponsorship routes are available.
  • 🌐
    Begin Google for Nonprofits applicationRegister with Goodstack (Google's Kenya validation partner). This runs alongside development and takes 2–4 weeks — start now to get Ad Grants approved close to launch.
  • 🏛
    Research one US fiscal sponsorship optionContact GlobalGiving or Africa Foundation USA to understand the application process and timeline. This unlocks US tax deductibility for donors — the biggest conversion improvement possible.
  • 🗄
    Set up Supabase — test auth, storage, and one RLS policyStand up a Supabase project. Verify: a user can log in, a file can be uploaded to Storage, and one database table has a working Row Level Security policy. This takes 2 hours and confirms the core architecture before you depend on it.
  • 📷
    Get 20–30 real field photos from the client NOWThe gallery and donation page need real photos of named beneficiaries with locations. "We'll use placeholders for now" is not acceptable — it delays the most trust-critical part of the site. Get them in Week 1.
  • 🗺
    Build the payment abstraction layer firstBefore any Pesapal integration, create a payment-service.js file that all payment calls route through. This single architectural decision makes migrating to Donorbox/Stripe later a 1-hour job instead of a 1-week refactor.
  • 📝
    Define Sanity CMS schemas alongside the React componentsEvery CMS-managed content area (projects, team, gallery, news) needs a Sanity schema defined in Week 1. This forces agreement on what the client can edit independently and prevents scope creep later.
  • 🔒
    Register with Kenya's Data Protection CommissionerThe Kenya Data Protection Act 2019 requires registration as a data controller before collecting personal data. The site collects donor names, emails, and financial information. This is a legal requirement, not a suggestion.

10 Things the Team Probably Hasn't Discussed Yet

Expert-level insights to bring to the meeting. Each one has a real impact on the project.

01

Kenya left the FATF grey list in June 2024

Previously, Kenya's grey list status made US institutional donors nervous about sending money. That barrier is now removed. Time the fundraising launch to take advantage of this improved trust posture.

02

PlanetScale removed its free plan in April 2024

Anyone on the team who researched the database stack before mid-2024 has outdated information. PlanetScale now starts at $39/month. Remove it from all consideration. Supabase is the replacement.

03

The chatbot should be human-staffed at launch, not AI

Donors who chat are close to converting. A human response (even delayed via email) builds relationship. AI feels cold for emotional causes like water access. Add AI in Phase 2 when there's budget.

04

Zeffy's "0% fees" doesn't apply to Kenya NGOs

Zeffy is North America–only and prompts donors for a 15–17% tip to Zeffy by default. It's not the free solution it seems for this project's geography.

05

Stripe cannot be opened in Kenya

Stripe isn't natively supported in Kenya. Getting a Stripe account requires incorporating a US company, opening a US bank account, and getting a US tax ID. That's a 2–6 month process — not a Week 1 option.

06

Set the donation form default to "Monthly" — 30–50% more recurring donors

This one UX change, backed by hundreds of A/B tests across US NPOs, increases monthly donor acquisition dramatically with no other changes to the page.

07

The gallery is a trust mechanism, not just a visual feature

US donors who can't visit Kenya use real photos as their proof of legitimacy. Named beneficiaries with geo-tagged locations (like charity: water pioneered) are the highest-trust feature an Africa-based NPO can offer.

08

Supabase's free tier pauses after 7 days of inactivity

If the site goes live on a free Supabase project, any quiet week will take the database offline. Upgrade to Pro ($25/month) before launch or set a daily automated ping to prevent inactivity.

09

Google Ad Grants gives $10,000/month in free ads — start the application in Week 1

Kenya-based NPOs are eligible. The application takes 2–4 weeks to approve. If you apply during development, it can be active by the time real users arrive. Missing the window means months of missed free advertising.

10

The biggest conversion problem isn't the design — it's missing US tax deductibility

A beautiful site with perfect UX still loses high-value US donors ($250+) who require a tax receipt. The technical team should build the donation page to support two paths from Day 1: direct (Pesapal, no deduction) and via a future US fiscal sponsor (tax-deductible). Even if the second path isn't live at launch, the UX hook should be in the wireframes now.
